# FlashCard App

A flashcard app that lets the user study or practice software enginering terminology. This app allows the user to generate a collection of terminolgy for different topics like, HTML basics, CSS Flexbox, JavaScript Functions, and more. In the app it includes a create deck button that allows you to create a new deck of terminologies. Each deck contains a count of cards they contain as well as a delete deck button. The decks are also clickable, which will direct the user to the deck carousel that allows them to view one terminology at a time of chosen topic. User can freely navigate through each term with the next or previous button and flip the card to see the decription of the term.

## Features:

- Navigation Menu
- Decks
- carousel
- terminology and descriptions
