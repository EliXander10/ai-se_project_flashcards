# FlashCards

A flashcard site that lets the user study or practice software engineering terminology. This site allows the user to generate a collection of terminology for different topics like HTML basics, CSS Flexbox, JavaScript Functions, and more. On this website it includes a create deck button that allows you to create a new deck of terminologies. When creating a new deck there are a variety of color choices to choose from for your deck and a text area to place JSON data. There is a placeholder inside of the text area to show the expected syntax to properly create a new deck. If there is any issue with data with color or text structure, an error modal will display explaining the issue that is preventing the creation of a new deck. Each new/existing deck will have a count of the cards it contains, as well as a delete deck button. The decks are clickable buttons, which will direct the user to the deck carousel that allows them to view one terminology at a time of chosen topic. Users can freely navigate through each term with the next or previous button and flip the card to see the description of the term. The decks are set up to be retrieved from an Api database as well as removed along with other functions of that specific deck. Each function used to create this website is explained using JSDocs to understand function, values, and results that are expected to be executed properly.
